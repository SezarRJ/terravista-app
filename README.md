# 🏡 TerraVista - AI-Powered Real Estate Platform

TerraVista is a comprehensive real estate platform that leverages AI to transform how people buy, sell, and invest in properties. Built with Next.js, TypeScript, and modern web technologies.

## 🚀 Features

### Core Platform
- **Smart Property Search** - AI-powered search with advanced filters and map integration
- **Real-time Messaging** - Instant communication between buyers, sellers, and agents
- **Multi-role Support** - Buyers, Sellers, Agents, and Admins with role-specific features
- **AI-Generated Content** - Automated property descriptions in multiple languages

### Investment Hub (Premium)
- **Investment Analysis** - ROI, IRR, and cash flow projections
- **Risk Assessment** - Monte Carlo simulations and scenario modeling
- **Market Intelligence** - Real-time market data and trends
- **Expert Consultation** - Connect with verified real estate professionals

### Advanced Features
- **Subscription Management** - Stripe-powered billing system
- **File Management** - AWS S3 integration for property images
- **Email Notifications** - Automated email workflows
- **Admin Dashboard** - Comprehensive platform management

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma ORM
- **Database**: PostgreSQL
- **Authentication**: NextAuth.js
- **Payments**: Stripe
- **Real-time**: Pusher
- **AI**: OpenAI GPT-4
- **Email**: Resend
- **Storage**: AWS S3
- **Maps**: Google Maps API
